# Team Task Manager (Full-Stack Project)
Team Task Manager is a full-stack web application designed to help teams efficiently manage projects, assign tasks, and track progress with role-based access control. The application allows users to sign up and log in securely using JWT-based authentication, with passwords hashed using bcrypt for enhanced security. It supports two types of users: Admin and Member. Admin users have the ability to create and manage projects, as well as assign tasks to team members, while Members can view and update the status of tasks assigned to them. Each project can include multiple users, and tasks are organized under projects with details such as title, assigned user, status (Pending, In Progress, Done), and due date. The dashboard provides an overview of all tasks, allowing users to monitor progress and identify overdue tasks easily.
The application is built using HTML, CSS, and JavaScript for the frontend, and Node.js with Express.js for the backend. MongoDB is used as the database with Mongoose for schema modeling, ensuring proper data structure and relationships between users, projects, and tasks. The backend exposes RESTful APIs for authentication, project management, and task handling. The project follows a clean folder structure with separate directories for models, routes, middleware, and frontend files, making it scalable and easy to maintain.
To run the project, users need to clone the repository, install dependencies using npm, and create a `.env` file in the backend directory with the MongoDB connection string (MONGO_URI) and a JWT secret key (JWT_SECRET). The server can be started using `node backend/server.js`, and it runs on http://localhost:5000. The application includes API endpoints for user signup and login, project creation (restricted to Admins), and task creation and retrieval.
The project is deployed using Railway, making it accessible via a live URL for demonstration and evaluation. The submission includes the deployed link, GitHub repository, README file, and a short demo video showcasing key features such as authentication, project creation, task assignment, and dashboard functionality. This project demonstrates core full-stack development skills including secure authentication, REST API design, database management, and deployment, while also maintaining a clear structure and user-friendly workflow.
